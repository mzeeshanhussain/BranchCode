Journey Dynamic Deep Link Data Demo

This page reads search-context query parameters directly from the URL and passes them into the Journey deep link via branch.setBranchViewData(), before the Journey banner renders. No page-by-page configuration is required — any page using this same snippet will automatically pick up whatever parameters are present in its URL.

Supported query parameters (all optional):

  • destination
  • checkin
  • checkout
  • guests
  • rate_code
  • screen — e.g. screen=Settings to route straight to a specific in-app screen instead of a search result
